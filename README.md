# TACOS LESSON

中学英語のやり直しから、日常会話を目指す1日5〜10分の英語アプリ。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例：`tacos-lesson`、**Public**）
2. このフォルダの中身を全部アップロードする（`index.html` がリポジトリの一番上に来るように）
3. リポジトリの **Settings → Pages** で、Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
4. 1〜2分待つと `https://ユーザー名.github.io/tacos-lesson/` で開けるようになる

## iPhone のホーム画面に追加する

1. 上のアドレスを **Safari** で開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」
3. 名前が「TACOS LESSON」になっているのを確認して「追加」

## アイコンを変える

`icons/` の3つの画像（180×180、192×192、512×512 の正方形 PNG）を差しかえる。
ホーム画面のアイコンを変えるときは、いったんホーム画面から削除して、もう一度追加する。

## 記録について

記録はその端末の Safari の中に保存されます。ほかの端末とは共有されません。
